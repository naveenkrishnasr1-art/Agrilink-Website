🌾 What is AgriLink? (Architecture & Pitch)

3-Sentence Pitch: "AgriLink is split into a Python FastAPI backend and a responsive, modern frontend. The backend hosts endpoints that run predictive price forecasting and batch-pooling algorithms for FPOs. The frontend interacts with these endpoints in real time, displaying dynamic data visualizations, gauges, and progressive aggregation metrics that empower farmers to make data-driven selling decisions."

🏗️ Technical Architecture

• Backend (`main.py`): FastAPI + Uvicorn server providing endpoints (`/health`, `/api/price-prediction`, `/api/marketplace/pool`, `/api/farmer/listing`, `/api/mandi-ticker`). CORS enabled.
• Frontend (`index.html`, `styles.css`, `app.js`): Real-time Chart.js rendering, SVG gauge needle rotation, SVG circular progress fill, and automated health probe with seamless offline simulation fallback.
